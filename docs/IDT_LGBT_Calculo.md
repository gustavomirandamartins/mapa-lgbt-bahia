# CÁLCULO DO ÍNDICE DE DESENVOLVIMENTO DO TURISMO LGBTQIAPN+ (IDT-LGBT)

> ⚠️ **Documento histórico**: descreve a metodologia de pontuação anterior (0–100, pesos por eixo). A metodologia vigente é de **mapeamento, sem pontuação** — o questionário oficial está em `lib/idt.ts` (`IDT_QUESTIONARIO`).

## Fórmula Geral

$$IDT - LGBT = \sum (Peso\ do\ Eixo 	imes Nota\ do\ Eixo)$$

Cada eixo recebe nota de:

| Situação | Pontuação |
| :--- | :--- |
| Não existe | 0 |
| Existe de forma inicial | 1 |
| Existe parcialmente | 2 |
| Existe de forma consolidada | 3 |
| Existe e é monitorado | 4 |

Depois, a nota é transformada em percentual.

## CÁLCULO FINAL

O sistema calcula:

**Exemplo**
* Governança: 15/20 = 75% -> 75 × 0,20 = 15 pontos.
* Legislação: 10/20 = 50% -> 50 × 0,15 = 7,5 pontos.

Repete-se o cálculo para todos os eixos.

Ao final:
$$IDT - LGBT = \sum Pontuação\ Ponderada$$

Resultado entre: **0 e 100**.
